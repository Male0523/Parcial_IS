## Interfaz y compatibilidad

La entrada antigua `envios.calc(p, z, c, d, cup=None, flag=False)` se conserva intacta como módulo legado. La entrada nueva vive en `src.calculadora`, usa nombres de parámetros explícitos y no admite `flag`. Los consumidores que adopten el módulo nuevo deben cambiar el import y eliminar ese argumento. Dado que se añadió una ruta distinta sin retirar la API heredada, se registra como 1.1.0. Una futura sustitución/eliminación de la interfaz anterior requeriría evaluar una versión major.
